ACCURAO REVIEWER — HOSTINGER PACKAGE
====================================

LOCAL PREVIEW
-------------
1. Extract the ZIP completely before opening it.
2. Keep index.html, the CSS files, site.js and the images folder together.
3. Double-click index.html. The site is packaged to work directly from your laptop.

HOSTINGER UPLOAD
----------------
1. Back up the current public_html folder.
2. Upload the CONTENTS of this package directly into public_html.
3. Include the hidden .htaccess file.
4. Make sure index.html is directly inside public_html, not in another folder.
5. Clear Hostinger and CDN caches after uploading.
